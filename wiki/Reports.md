# Reports

S1 Command Center generates professional reports after backup/restore operations and from any operations page.

## Report Formats

| Format | Extension | Best For |
|--------|-----------|----------|
| **HTML** | `.html` | Customer-facing reports, visual review |
| **Excel** | `.xlsx` | Data analysis, filtering, pivots |
| **JSON** | `.json` | Programmatic processing, automation |
| **CSV** | `.csv` | Unified Alerts export |

## Restore Report (HTML)

The restore HTML report includes:

### Summary Cards
- Total nodes restored
- Nodes skipped
- Errors encountered
- Total elements created

### Connection Info
- Source and destination console URLs
- Backup file path
- Restore timestamp and duration

### Per-Node Breakdown
Each node (account/site/group) shows:
- Node path and type
- Color-coded status badge (done/error/skipped)
- Element-by-element breakdown with counts

### Failed Items Table
Every individual item that failed to restore:
- Element type (exclusion, STAR rule, etc.)
- Item name/value
- Exact API error message

### Operation Log
Collapsible full log of every action taken during the restore.

## Operations Page Reports

Every operations page has an **Export Report** button that exports the current table data.

### Agents Report
- Computer name, OS, agent version, machine type, active status
- Summary: total agent count

### Threats Report
- Threat ID, classification, computer name, mitigation status, date, name
- Summary: total threat count

### Accounts & Sites Report
- Account/site/group hierarchy with IDs
- Summary: account, site, and group counts

## Export Utility

Reports are generated by `export_utils.py`. The HTML template features:
- Dark theme matching the app's visual style
- Responsive layout
- Sortable tables
- Summary statistics cards
- Auto-opens in the default browser after export
